# AWS プロジェクトコスト分析レポート

このドキュメントは、terraform_agentcoreプロジェクトの月間コスト試算をまとめたものです。

## プロジェクト概要

**プロジェクト**: terraform_agentcore
**リージョン**: ap-northeast-1 (東京)
**アーキテクチャ**: Bedrock AgentCore + Strands Agents + Claude Sonnet 4.5

### 使用サービス一覧

| サービス | 用途 |
|---------|------|
| Bedrock AgentCore Runtime | エージェントのサーバーレスホスティング |
| Bedrock AgentCore Memory | 短期/長期メモリ管理 |
| Bedrock (Claude Sonnet 4.5) | 基盤モデル推論 |
| ECR | Dockerイメージストレージ |
| S3 | トリガーバケット、Terraformステート |
| CloudWatch Logs | ログ収集・保存 |
| Lambda | S3イベントトリガー |
| IAM | 無料 |

## コスト最適化の推奨事項

### 即時対応

1. **プロンプトキャッシュの活用** - 最大90%のトークンコスト削減
2. **バッチ処理の検討** - 非同期処理で50%コスト削減
3. **カスタムメモリ戦略** - 長期メモリコストを$0.75→$0.25/1000に削減

### ベストプラクティス

1. **トークン効率化** - プロンプトを最適化して入出力トークンを削減
2. **ログレベル調整** - 本番環境では必要なログのみ出力
3. **S3ライフサイクル** - 古いファイルを自動削除/アーカイブ

## 注意事項・免責

- 料金は2025年1月時点のAWS公開情報に基づく
- 東京リージョン（ap-northeast-1）の料金を適用
- 実際のコストは使用パターンにより変動
- データ転送料金は除外（同一リージョン内は無料）
- AgentCoreプレビュー期間（〜2025年9月16日）は無料
